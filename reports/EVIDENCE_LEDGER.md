# EVIDENCE LEDGER — GCI WORLD 2026 FINAL ASSIGNMENT

Sổ cái theo dõi bằng chứng (Evidence Ledger) là nguồn sự thật duy nhất (Single Source of Truth) kết nối dữ liệu thô, kết quả chạy code thực tế, giả thuyết và số liệu đưa lên slide/proposal.

**Quy tắc phân loại Evidence Type:**
- `DATA`: Số liệu/kết quả tính toán trực tiếp từ dataset bằng code thực thi trong workspace.
- `SOURCE`: Số liệu/dữ kiện từ tài liệu thị trường, báo cáo ngành hoặc nghiên cứu học thuật đã xác minh nguồn.
- `ASSUMPTION`: Giả định mô hình, giả định kinh doanh hoặc tham số kịch bản cần kiểm chứng.
- `TODO / UNVERIFIED`: Chưa được kiểm chứng hoặc chưa chạy code thực tế.
